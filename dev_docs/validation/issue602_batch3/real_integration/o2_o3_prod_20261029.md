## O-3：首屏直接切全局 Chat 不再被误报为故障

**修复前**（`rdlens.32`，见 `source_prod_20261028/source_404_and_viewport.md` O-3）：首屏切 Chat → `bootstrap` `net::ERR_ABORTED`、save state 卡 `Loading research workspace…`、门禁提示 `An unexpected error occurred…`、`chat-send` 恒 disabled、需点 `New session` 恢复。

**根因更正**：`ERR_ABORTED` **不是根因**。它来自子页 StrictMode 双挂载发出两条 nonce 不同的 `ready`（实测间隔 2ms），第二个被当作 iframe reload 触发 `replaceBinding` → `abortActiveRequest()`（`parentSession.ts:112`）取消首个 bootstrap。对照实验：先 `New session` 再切 Chat，`ERR_ABORTED` **同样出现**但 Chat 完全正常 → 属幂等首帧竞争的无害噪声。
**真正根因**：`editorSnapshot===null` 在「未创建会话」时被 composer 同时投影成 `unavailable`（“Loading research workspace…”）与 gate `runtime_unavailable`（“An unexpected error occurred…”），把正常空态渲染成故障。

**修复**（fork PR #102，`d110fec`）：`ResearchChatPanel` 新增 `noActiveSession = wired && sessionRef === null`（仅**显式** null，`undefined` 语义不变）→ 该态不渲染 composer/保存状态/门禁/scope bar，改渲染 `chat-no-session` 指路空态；**不在面板内加创建按钮**（DESIGN §4.3 创建入口唯一＝Header）。
